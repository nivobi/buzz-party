# Code of conduct

Buzz Party is a party game; the project should feel like one too.

- Be kind and patient, especially with people who are new to this.
- Disagree about ideas, never about people. Assume good intent.
- No harassment, insults, or unwelcome sexual or discriminatory remarks, in
  issues, pull requests or anywhere else the project lives.
- Stay on topic and keep discussions useful for whoever reads them later.

If someone breaks these rules, the maintainer may edit or remove their
comments and block them from the project. To report a problem privately,
use the contact on the maintainer's [GitHub profile](https://github.com/nivobi).
